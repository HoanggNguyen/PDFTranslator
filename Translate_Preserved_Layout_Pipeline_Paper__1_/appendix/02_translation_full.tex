Two anomalies are worth keeping in mind when reading
Table~\ref{tab:appendix-comet-full}:

\begin{enumerate}
    \item \textbf{Serbian (\texttt{sr\_RS}) --- an extreme chrF++ spread across
    systems} (5.1--40.4) despite a much smaller COMET spread. The cause is that
    some systems translate into Cyrillic while the reference uses Latin script
    (or vice versa), which collapses chrF++ (surface character matching) while
    barely affecting COMET (semantic matching through embeddings). This is a
    direct illustration of the limitation of lexical metrics discussed in
    Section~\ref{subsec:lit-models}.

    \item \textbf{CJK languages (\texttt{ja\_JP}, \texttt{ko\_KR},
    \texttt{zh\_CN}/\texttt{zh\_TW}) --- low chrF++ on every system}
    ($\approx$~26--34) despite high COMET, because these languages do not
    separate words with spaces. This does \emph{not} indicate poor translation.
\end{enumerate}
